Think Before You Click
CyberSafe India is a cybersecurity awareness project designed to educate people about online scams, suspicious links, password safety and cybercrime reporting.
🎯 Project Objective
To help Indian citizens identify cyber threats, protect their personal information and stay safe online.
🚀 Features
🔍 Scam Message Analyser
🔗 Suspicious URL Checker
🔐 Password Strength Guide
📚 Cybersecurity Learning Centre
🧠 Interactive Cybersecurity Quiz
📊 Cyber Safety Score Calculator
🚨 Cybercrime Reporting Guide
🎮 Interactive Cyber Scam Simulator
🌐 English, Hindi and Kannada language support
🛠️ Technologies Used
React
TypeScript
HTML
CSS
JavaScript
🇮🇳 Important Cybercrime Resources
Cybercrime Helpline: 1930
Official Reporting Portal: https://cybercrime.gov.in/
🔒 Privacy
CyberSafe India uses local checks for its educational tools. It is designed not to transmit or store passwords entered into the password guide.
